Video Compressor

Shrink any video to an exact file size or a target quality. CLI, desktop GUI, and a local web app. Powered by ffmpeg, zero Python dependencies.

Install Usage GitHub

Why it's different

Exact-size 2-pass encode

Software mode runs two-pass x264 so the result lands within ~2% of the MiB target you ask for.

Hardware acceleration

Optional NVENC, VAAPI and VideoToolbox single-pass encoding when you want speed over precision.

Three interfaces

A scriptable CLI, a native tkinter GUI, and a browser web UI that never uploads your files anywhere.

Web-ready output

H.264/AAC MP4 with +faststart so compressed videos stream instantly.

Install

pip install 'scales-video-compressor[web]' # from PyPI, web UI included
pip install . # or from source (CLI + GUI)

You need Python 3.9+ and ffmpeg/ffprobe on your PATH.

Usage

video-compressor compress input.mp4 # quality, CRF 23
video-compressor compress input.mp4 -s 100 # target ~100 MiB
video-compressor compress input.mp4 -s 64 -p veryslow
video-compressor compress input.mp4 -c 18 -e nvenc # hardware encode
video-compressor web # open the web UI
video-compressor gui # desktop app

Options

FlagMeaning
-s, --size MiBTarget output size (2-pass encode).
-c, --crf NConstant Rate Factor: 18 high, 23 good, 28 small.
-e, --encodersoftware, nvenc, vaapi or videotoolbox.
-o, --output FILEOutput path (default: INPUT_compressed.mp4).
-p, --presetx264 speed/compression (ultrafast … veryslow).
-a, --audio-kbps NAudio bitrate (default 128).

How the size math works

total = S × 8 × 1024 ÷ D # kbps overall
video = total × 0.95 − audio # 5% headroom for the container
